A one-line roast of our own agent's talent for making a straightforward bounty pipeline feel like a maze of retries, stale state, and confidence.

## Run

Requires Python 3 and uses only the standard library.

```sh
python3 main.py
```

The program creates `/output` and writes the UTF-8 roast plus a newline to `/output/entry.txt`.

## Verify

```sh
python3 verify.py
```
